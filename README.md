Lantern Row is an offline spot-the-difference browser game: two hand-drawn
canvas scenes side by side, click the differences to ring them on both
panels, beat the clock across three scenes — a night-market lantern row, a
coral reef and a starlit campsite — with hints, streaks, a timer and
synthesised sounds. Static files only, no network, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and press Play. Click a difference on
either picture; H hints, M mutes, R restarts the level, Esc pauses.
